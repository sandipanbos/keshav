# Keshav Mazumdar — Personal Profile Website

A responsive static website built with HTML and CSS. The supplied composite image is used in two ways:
- The right-hand personal photograph is displayed beside and wrapped by the profile text.
- The complete commemorative memoir is shown in its own section.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `keshav-mazumdar-profile`).
2. Upload **all files and folders** in this project, keeping the `assets` folder structure.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish the site. The public URL will appear in the Pages settings.

## Before publishing
Please review every biographical statement, credential, endorsement and charitable-giving figure. The site distinguishes supplied personal claims from independently verified facts and includes a disclaimer that it is not an official government, military or institutional website. Do not add classified or operational information.
